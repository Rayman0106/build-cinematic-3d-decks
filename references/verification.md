# 验证、证据与问题排查

## 四层证据

| 层 | 可以证明 | 不能证明 |
|---|---|---|
| 语法/构建/资源 | 能解析、依赖齐、产物可重建 | 动作自然、画面清楚 |
| 数值/几何 | 端点、锚点、速度、接触、数据正确 | 整体节奏与艺术质量 |
| 静帧/拼图 | 构图、穿模、字体、典型姿势 | 正常速度小顿挫/闪烁 |
| 正常速度播放/试听 | 节奏、瞬态、阅读、闪烁、音调 | 未测试设备的性能保证 |

F1 的一次失败是只看关键帧和 check 就声称贴合无卡顿，随后用户否定。把“通过什么”写明，别把一次通过等价到下一层。

## 最小回归矩阵

| 路径 | 要看什么 |
|---|---|
| 冷启动→Ready | 进度有效，无黑屏；未自动播放 |
| Start→全屏 | 手势、尺寸、相机/DOM同步 |
| 上页末→转场首 | 完整状态和屏幕关键点连续 |
| 转场末→阅读 | 无二次挪动、字幕提前或补字跳帧 |
| 直接跳页/反向/重播 | 无残留透明、轮廓、材质或随机漂移 |
| 窗口/全屏/不同 aspect | 主体不越界、字不过小、锚点一致 |
| reduced motion/无声/WebGL失败 | 信息仍可达，错误可解释 |

实际修改哪段，就先覆盖那段和相邻边界。已通过的测试不无理由反复全部重跑；新风险或新改动出现再扩展。

## 常见问题的受控对照

### 灰面闪烁

锁相机静态→只动相机→关阴影→纯色材质→逐组隐藏重复面。若关阴影仍在、补体与原立面共享深度，优先 z-fighting；不要把所有材质 roughness 改一遍。保留用户圈选区域、时间和最终 root cause。

### 转场小顿一下

把 frame time、scene time、pose phase、worldAmount、contentBornAt 同时打印。frame time尖峰是运行时；frame time稳定但 position导数归零可能是路径；pose reset 是状态。别只延长 easing 掩盖。

### 车/手穿模

在最终机位和俯视/侧视对照，显示语义碰撞体和路径。根据真实 body surface，不凭节点名。角色的临时躯干修正可能破坏手接触，修后复查上下游。

### 字最后一帧突然补满

比较 t=.97/.99/1 的 alpha coverage，检查是否动画层漏像素、角/衬线未归笔画、最终 DOM 替换才填满。每个 glyph opaque pixel 预分配到达时刻，不能在最后靠方形 wipe 收尾。

### 粒子来源不明

输出每个 sourceId/group/from/to，首帧叠加实际图表。两来源都要在对应区间有贡献，不从隐藏图标或随机屏幕角落出发。图表与字体交互要在正常速度下足够显眼。

## 可重复检查工具

- `test-kernel.mjs`：裁切、轮廓方向/循环起点、投影单位。
- `test-motion.mjs`：确定性、位移单调、速度/位置端点、双来源、反向沿线、所有字形像素到达、IK。
- `validate_storyboard.py`：有意义的时间区间、角色身份、相邻端点。
- `check-continuity.py`：world 或 screen edge；缺比较字段必须失败。
- `inspect_glb.py`：读取容器与元数据，不做隐藏修改。

允许导出 project snapshot 时，把真实导出代入；示例 fixture 通过只说明工具工作，不算项目本身通过。

## 浏览器与录像限制

在授权的浏览器/工具里观察。打不开或被安全限制时明确说“未实测”，不换 headless/localhost/隐藏调试通道绕过同一限制。可以继续静态/数值/构建工作，但不能据此声称已看过。用户授权新访问后，按工具规则重新检查。

视频只有需要交付或确有检查收益时录。内部问题短片比整套四分钟重录更直接。最终记录日期、源码 commit、测试命令、结果、正常速度是否实测、设备/浏览器范围。
