# 场景、真实部件与材质稳定性

## 先查资产结构

加载模型后查看节点、网格、材质、UV、轴向、包围盒、轮心及局部变换。节点叫 Rear_Wing 并不证明整个尾翼在里面；本项目有一个同名节点主要装着贴花，尾翼实体留在 Body。前翼也曾因按三角形中心粗切，留下端板和向后延伸的翼片。

拆部件时按连通组件和实际三角形检查。保留索引、normal、tangent、UV、材料分组及世界变换；确认原位没有真实几何残留。复用坐标阈值只适用于已核对的模型，换模型后重新划分。

把部件从父组移到强调组时保存 matrixWorld，换父后恢复等价变换。回装使用原始挂点状态，检查整个组件，不只验证一两个顶点。放大／高亮只影响取出的部件，并能完全恢复。

## 遮挡是一项构图问题

相机到主体、预算柱、文字落区的视线都需检查。道路护栏、树冠、立柱、看台不应挡住需要读懂的东西。优先重新安排机位、目标或背景资产；确需遮挡掩码时按镜头视廊控制，并完整恢复退出状态。

扩大视廊要移动树干、树冠、枝叶和阴影整体，不只隐藏叶子。使用远侧看台保留地点识别，不能为了避遮挡把整个环境退化成一个平面轮廓。其它车可以自然放到远处，不应遮住数据。

多车构图同时看世界与屏幕：世界几何不穿模，屏幕车鼻、驾驶舱、标识和主要轮胎能辨认。AABB／OBB 可做粗筛；最终视角还需看轮廓和可见面积。不同方向、尺度和疏密服务构图，不以“填满画面”允许互相穿透。

## 常见症状与诊断

| 症状 | 优先检查 | 处理方向 |
|---|---|---|
| 车下半部分透明／消失 | 整车 fade、透明排序、深度、地面高度、clip | 保持主体 opaque；检查合成与地面关系 |
| 运动时灰色表面来回闪 | 重复／共面面片、补实体与原立面、远近裁面 | 清理冲突面；已核对场景可偏移补面或调整深度偏置 |
| 栏杆／铁网边缘闪 | alpha cutout、采样与 MSAA、纹理过滤 | 保留 alphaTest 语义，测试适合当前渲染器的边缘覆盖 |
| 切入场景天空变色 | 直接／离屏色彩管理、tone mapping、曝光、背景透明 | 同一色彩流程合成；不要每段重设曝光 |
| 看台像镂空没加载 | 资产本来只有薄板、背面、丢失网格 | 保留原外观，补实际承重体而非画一块壁纸 |
| 贴图原文件清晰但屏幕糊 | draw buffer、DPR、LOD 的 UV 混合、压缩、斜视采样 | 保留纹理接缝和材质边界，按显示需求调整质量 |
| 轮胎颤动／裂缝／多余色环 | rolling 与 steering 轴、父组、重复轮胎层、UV、blur | 轮心定位、层级分离、可重复角度与有限模糊 |
| 拆部件后残留白色轮廓 | 旧 overlay、选中效果、其它场景状态 | 移除或归零残留，只强调实际取出的组件 |

共面深度冲突不是阴影闪烁或 alpha 边缘闪烁。先做受控对照和运动中的局部检查，避免一次改全部材质再把静帧改善当成解决。

本项目看台修复是原立面与新混凝土补体共面；保留真实外观，用补体偏置消除交替争夺像素。polygonOffset 的数值依赖几何和相机范围，不能把它应用到所有车辆和装饰网格。

## 车轮与关节

旋转来自路径累计里程除以实际半径，而不是每帧 angle += speed × dt。保存原相位，对各轮心沿对应轮胎前向积分，再用绝对时间查询；跨段带上前段总里程。这样跳页、倒退和重新渲染不会改变轮胎位置。

前轮转向与 rolling 分层。轨迹、heading、steer 与轮心速度有同一来源；不要既由车身旋转带动车轮，又额外重复施加姿态。模糊只在速度和显示条件需要时添加，保留侧壁字标、胎面和中心一致。

## 迭代动画要有版本感

从基线车取出完整组件 → 清楚展示改进 → 回装 → 测试／对照 → 下一次修订。只让一片涂装飞出来不会被理解成升级。用版本、几何变化或前后效果说明“为什么改”，而不是把复杂图形堆在赛车旁。

## 材质和调试记录

统一色彩空间、环境照明、roughness／metalness 的含义。真实感优先来自正确几何、光照与纹理，不来自全局加高光或 bloom。共享材质修改前明确作用对象，避免一个车队的透明度影响其它克隆。

验证记录保留根因、改动范围、对照片段及仍未测试的条件；不能把“数值没错”“编译通过”写成材质已经好看。
