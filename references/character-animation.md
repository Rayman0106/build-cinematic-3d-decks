# 人物：关节、接触、动作模板与衣物

## 症状不都来自缓动

| 观感 | 常见原因 | 对照 |
|---|---|---|
| 一直前后摇 | root/pelvis/spine 重复加周期 | 关 secondary，查根轨迹 |
| 小臂动手掌平行 | 世界方向锁手，腕未继承 | 显示局部轴，单骨测试 |
| 手抽出穿肚子 | 接触点直线插值无避障 | 轨迹与躯干碰撞体 |
| 裤子粘连/腿岔开 | skin 权重/裆部拓扑/姿态 | rest pose 与单腿屈曲 |
| 最后一脚抽搐 | clip 切换/接触迟撤/±π | 足底世界轨迹及接触区间 |
| 鞠躬还直视 | gaze 盖过躯干与头姿态 | 关 gaze 看局部头颈 |
| 腿穿椅子 | 站起顺序/椅轨/根移动 | 座面和腿部碰撞体 |

把整体外移可藏穿模却破坏接触。动作、骨架、皮肤和道具分别查。

## 复杂表演使用已授权模板

舞蹈、走路优先找动作模板，不随机摇几十根骨头。看完整循环、起止、转身和脚部。Mesh2Motion/Quaternius 或 Mixamo 等都要分别核对工具代码与动作许可，GitHub 工具 MIT 不等于动作 CC0。

数学公开源码保留允许再分发的动作，课堂成品可选 Mixamo 与原始数据分开。参考 [数学案例](reaction-time-case-study.md)。梗舞服从场合和用户意图，不是演示默认必备。

## 重定向

1. 比较 bind/rest pose、A/T pose、朝向、单位、hip 高度。
2. 映射 root、pelvis、spine、neck/head、上下臂、手、腿、脚/趾；名字只是候选。
3. 在源/目标 rest frame 和父空间之间转换旋转，不把 world quaternion 写到 local bone。
4. 明确 root motion 保留/去除/给场景 root，避免双重前进。
5. 重采样，四元数同半球，slerp，匹配片段边界和导数。
6. 接触区间用短时 IK 修正，不永久盖过源动作。
7. 极端姿势通过后再加 gaze 与微表演。

SkeletonUtils 可 clone/retargetClip，但需核对版本与参数。FBX 缩放补偿节点会影响蒙皮/inverse bind，不能只改 parent。保留源文件，对照 rigid hierarchy 调整后的 rest pose。

## 手臂链

肩→上臂→肘→前臂扭转→腕→手→指；目标包含位置与朝向，不只一个点。两段 IK 解肘，pole 约束方向，旋转对齐实际本地轴；不可达时平滑限制，不突然翻肘。

`assets/semantic-motion.mjs` 的平面 IK 是最小机制示例，实际三维 pole 和关节限制需扩展。

67 手势用双手反相目标，上臂/肘参与，腕略滞后并随前臂变角。进入先释放桌面，用外侧弧线避身体；退出落稳。循环自然不代表前后链条也自然。

鼠标姿态先定位掌根，再手指包覆；把手放模型中心常像抓球。键盘动作按实际键帽定位，不按整个 PC bounds。

## 脚底与站起

接触要求鞋底的世界位置/朝向稳定，不是踝骨 local 位置稳定。标记 stance 时间，root 走动不能把脚锁在旧世界点过久。

```text
释放鼠标 → 椅后移 → 重心前移 → 伸膝髋站起
→ 双脚稳定 → 表演 → 稳定支撑 → 鞠躬
```

抬脚有 swing 高度，落地保持。最后不能突然被 idle 拉回。全身 crossfade 不保证足底连续，混合期间仍查脚速、穿地和接触。

## 全身联动与衣物

鞠躬由髋和脊柱共同完成，头颈跟随且下视，手臂自然，足底支撑；不照搬某个角度为通则。抬手有准备、肘腕时间差及适度躯干跟随；root 随机正弦不等于呼吸。

裤腿粘连查双腿权重与裆部拓扑，模型不适合大开胯就缩动作或换资产。修形只影响目标皮肤区域，保留纹理、法线与可撤销记录。显示器和扬声器按旋转后实体定位，先修 roughness/色彩/法线，不用全局亮漆。

验收看完整片段及最后半秒；静帧最容易漏最后一脚。
