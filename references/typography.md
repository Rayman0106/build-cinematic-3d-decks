# 统一字体与可变文字动画

## 稳定的文字系统

选主字体和真实中文／多语言回退，统一标题、正文、数字、按钮、字幕。靠字号、字重、行距、字距和颜色表达层级，不靠每页换字体。数字比较可用等宽数字；font-family 名称存在不表示对应资产已加载。

品牌页可以例外：各品牌字标的字体、颜色和 Logo 不同，说明、编号和导航仍用主字体。Logo 保留原资产比例，字标不能替代用户要求的 Logo。许可随工程保留，经验 skill 不包含这些资产的使用权。

## 先核对字效库

本次提供的库中：

| 标签 | 实际效果 | 合适用途 |
|---|---|---|
| B / roll | 透视翻入 | 开篇、新章节 |
| C / ink | 描边填色 | 结构变实体、规则、概念形成 |
| D / sweep | 光带扫过 | 品牌检阅、逐行强调 |
| F / pixel | 粒子组字 | 研发、组合、数据聚合 |
| G / trail | 多层错位汇合 | 因果汇总、速度、最终收敛 |
| I / blade | 斜刃揭幕 | 限制、切分、边界 |
| J / fold | 波浪折入 | 层次／章节展开的候选 |

正式版代码把粒子效果命名为 particle。字母只对这个库有效。用户把 E 改为 D 时用 sweep，不继续旧版本。并非所有候选都在最终版落地，也无需全部用上。

动效服从语义与读图负担。正文先保证阅读，标题可以变化。完成后落回完整的原生文字，不让粒子、重影或描边占据整段讲解。

## 字形、时间与编辑

- `document.fonts.load(...)` 后等待 fonts.ready，Logo decode 后再计算布局。
- ink／particle 从实际加载的字形提取路径与采样，不给不同字体套假轮廓。
- 原生 DOM 文本保留编辑与可访问性；装饰副本 aria-hidden，不参与导出。序列化时移除效果层。
- 时间来自场景绝对时间减文字出生时刻。字幕文案切换与出现时间都在同一时间线上。
- 首次绘制前初始化可见状态，尤其末页不能先闪出完整标题再隐藏重播。
- 静态页、跳页、减少动态偏好直接显示完整文字，清除遗留滤镜、clip-path 与粒子。

## 颜色与衬托

浅底用深字，暗底用浅字。运动背景检查文字所在区域，不只看整页平均色；可预采样后平滑切墨色，或把文字放在稳定区域。

优先调整位置、颜色、字号、留白，不默认给每字／每行加白盒。确需衬托时可选择一个整体柔和渐变区域，再按用户偏好执行。用户已要求全部去除时，不保留隐性白色 halo。暗色品牌面板对齐画面边缘并给上下内容足够空间。

F1 检阅的黑色字标面板最终贴左上角，普通页面的白色衬托全部删除；这是案例决定，不是所有演示必须采用的版式。

## 验证

在最终字体、真实背景与最终缩放下检查浅底浅字、标题裁切、设备阅读尺寸、Logo 和静态阅读。正常速度观察字幕是否对应对象动作。字效标签匹配、fonts.ready 通过不能证明文字可见。

## 数学项目：把字效变成内容动作

| 内容关系 | 可以做的动画 | 来源与落点 |
|---|---|---|
| 两种条件的影响 | 双来源粒子共同组成判断词 | 左右实际图形/数据点→标题 |
| mean/median | 现有点聚合成关键词，再回到可读字 | 图中点→相应词，保留组色 |
| 文本归纳 | 从下方真实段落抽取对应字母重组 | Range 测量源/目标字母，不从图标随机生字 |
| 曲线解释 | 笔尖沿原曲线走，随后引出文字 | 曲线本身→相关概念，不画两条无关线 |
| 限制/结论 | outline→fill、折叠、分色收敛 | 字形结构稳定，不新增未经支持内容 |
| 两点书写 | 两笔尖各负责真实笔顺 | 笔尖与 ink 使用同一个路径和进度 |

第9页 slowed down 被认可，后续要求是聚合方式与下一页呼应，来源同时涵盖左右图形；不是随便换成另一种 particle。用户明确认可的效果应单独保存，改别页不覆写它。

## 粒子的实现步骤

1. 字体就绪后，在目标实际尺寸 raster 字形或采样字路径。最终目标位置与原生文字 layout 共用。
2. 从真实 SVG/Canvas/DOM 锚点取源。SVG 内点用 getScreenCTM/坐标变换，不把 element bounds 中心当全部数据点。
3. 每个粒子保存 stable id、sourceId、group、from、to、birth、travel。双来源使用交替/分组配额，避免随机后某来源缺席。
4. 速度先离开源结构、沿有意图弧线移动、逐渐稳定。各点延迟少量且确定；不要统一瞬间爆炸。
5. 到位后保持短暂形状，再与完整 DOM 交接。粒子与文字的字体/字号/字距不一致会双影或跳字。

在场景真正入场前隐藏目标词；不能 full title 先闪出再让粒子重写。静态跳页/减少动态模式直接显示完整 DOM。

## 逐字母沿笔画填充，不是左到右扫描

单纯 stroke-dashoffset 沿 glyph 外轮廓跑，不等于人写字的中心笔顺。若要按笔画显现，准备每字的中心线序列或已授权的笔顺数据。不能把所有字母当圆圈；中文、连字、阿拉伯字形等需要实际文字系统支持。

可用两种方案：

- **SVG mask**：笔顺 path 以足够宽的 round cap/join 笔触写入 mask，裁到真实 glyph fill。校验转角、端点与衬线都覆盖；宽度不足会在最后换 DOM 时补角。
- **像素到达表**：对实际 glyph 的每个非透明像素，寻找它所属字母的最近中心线，按累计弧长分配到达时间。时间可加曲率/抬笔权重。渲染时仅查询该表，所有像素在结束前填满，取消最后的补字机制。

```js
const arrival = stroke.start + stroke.duration * fractionAlongStroke;
const alpha = originalGlyphAlpha * smooth5((time - arrival) / feather);
```

上式是简化机制；字形与中心线必须同坐标、同一字母分组，不能让 D 的像素归到旁边 A 的笔画。实验室的 nearest-centerline 方法有意依赖手工笔顺，不自动推断任意字体。生产中的 kerning、连字和复杂脚本需经过文本 shaping；按字符逐个 measureText 可能不适合。

原项目 [letter-ink.js](https://github.com/Rayman0106/reaction-time-math-3d-deck/blob/main/src/letter-ink.js) 为角、端点和衬线提前分配时刻，并包含抬笔距离/弯曲速度；实例模块 `assets/semantic-motion.mjs` 演示最小版本。

## 笔尖与笔迹的关系

笔尖查询的应是相同 path 的相同弧长，不另画一条更好看的曲线。笔画之间抬笔有可见移动和短暂停顿，不能从一笔末端瞬移到下一笔起点。两个点像两个笔尖时，分别有明确负责的字/笔画；光点只是悬在字旁没有互动，不算完成。

字符从正文拼出来时，源 Range 的实际字母匹配目标字母，保留原段落阅读；装饰副本 aria-hidden，清理时移除。找不到对应字母可改表达或说明是图形构成，不编造来源。

## 语义字效与可访问性

保留标题的原生文本，装饰画布不替代语义；动画期间视觉隐藏仍可保留 screen reader 文本。减少动态偏好下直接落到完整字，键盘导航可用。字效不应让讲稿中一个词到下一页仍未写完。

正文一般不逐字大特效。统一字体不等于所有页同一入场；按叙事换翻入、分色、描边、聚合、折叠，但每种都能解释“它为什么从这里出现”。
